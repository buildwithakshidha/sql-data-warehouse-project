# Modern Data Warehouse & Analytics

An end-to-end Data Engineering and Analytics project built using SQL Server.

This project focuses on building a modern data warehouse by integrating data from ERP and CRM source systems. The raw data is cleaned, transformed, and consolidated into a user-friendly analytical data model to support SQL-based reporting and business insights.

## 🎯 Objectives

- Build a modern data warehouse using SQL Server
- Integrate ERP and CRM source data
- Perform data cleansing and transformation
- Design an analytical data model
- Develop SQL queries for business analysis
- Generate meaningful insights from sales data
- Document the complete data architecture and data model
